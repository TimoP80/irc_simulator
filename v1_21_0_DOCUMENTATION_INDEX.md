## 🎓 Key Concepts

### Configuration Sync
- **What:** Settings sync between web and Electron
- **How:** IndexedDB + BroadcastChannel + IPC
- **Why:** Consistent experience across platforms
- **Where:** `CONFIG_SYNC_QUICK_START.md`

### PM Response Delay
- **What:** Typing delays for fallback responses
- **How:** Restructured degraded mode handling
- **Why:** Maintain immersion during API failures
- **Where:** `VERSION_1_21_0_RELEASE_NOTES.md`

### Storage Layers
- **Web:** IndexedDB (primary) + localStorage (fallback)
- **Electron:** File-based JSON storage
- **Priority:** Electron → IndexedDB → localStorage
- **Where:** `CONFIG_SYNC_IMPLEMENTATION_SUMMARY.md`
