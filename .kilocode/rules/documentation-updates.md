## Brief overview
This rule defines the process for updating documentation when new features are added or existing features are modified.

## Documentation Update Rule
- Whenever a new feature is implemented or an existing feature is changed, the `changelog.md` and `readme.md` files must be updated.
- The `changelog.md` should contain a description of the changes, including the date and version.
- The `readme.md` should be updated to reflect any changes in functionality, usage, or installation.
